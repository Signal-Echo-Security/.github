# Signal Echo Security

<img src="https://raw.githubusercontent.com/Signal-Echo-Security/.github/main/profile/signal-echo-logo.png" alt="Signal Echo logo" width="104" />

Signal Echo helps people spot online scams, work out what to do, and pass useful warnings on to others.

We’re starting in Spain with Spanish-language guidance for suspicious bank and delivery messages. The first release will combine explanations from Maya with practical steps based on official sources.

[**Explore Signal Echo**](https://github.com/Signal-Echo-Security/hub-signalecho) · [**Share a product idea**](https://github.com/Signal-Echo-Security/hub-signalecho/issues)
